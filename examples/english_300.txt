Natural language processing helps computers work with human language. People use language to explain ideas, ask questions, share knowledge, and describe experiences. A computer receives this language as text, but analysis requires rules. The first step is to prepare the text without removing information that matters for the task.

Sentence tokenization divides a document into sentences. Word tokenization then identifies the words inside those sentences. These operations sound simple, yet punctuation, abbreviations, numbers, and different writing systems can create ambiguity. A reliable program should explain its decisions so that another reader can reproduce the same result from the same input.

Frequency analysis counts how often each word appears. The total word count measures the size of the text, while the number of unique words describes its vocabulary. The most frequent words reveal repeated patterns. Common words should remain in this homework because removing them would change the requested frequency distribution.

Different languages introduce challenges. Persian includes letters with alternative Arabic forms and often uses a joining character within a word. English contains contractions and abbreviations. Some languages do not normally separate every word with spaces. Therefore, accepting Unicode text is helpful, but accurate linguistic segmentation still depends on the language.

This project makes the basic analysis transparent and repeatable. It accepts a text file or pasted text, reports sentence and word counts, lists unique vocabulary, and displays the ten most frequent words. Its output also records the selected counting options. Tests cover examples, empty input, punctuation, mixed scripts, and normalization behavior.

A small tool can demonstrate important principles of software development. Clear documentation connects the implementation to the assignment. Consistent output makes verification easier. Meaningful tests expose mistakes before submission. Most importantly, explicit assumptions help users understand what the results represent and where more advanced language processing would be necessary.
